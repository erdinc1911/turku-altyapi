# Türkü Altyapı

Saz eşliğinde veya yalnız vokalle söylenmiş türkülere, tablette çevrimdışı çalışarak
uyumlu bir müzik altyapısı (bas, perküsyon, yaylılar, pad) ekleyen Android uygulaması.

Durum: Aşama 0 — ilk APK iskeleti hazırlanıyor.

Teknik değerlendirme ve yol haritası proje dokümanında tutulur.
